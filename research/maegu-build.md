# Maegu skill builds — research

Compiled 2026-08-21 for a returning Lv62 Maegu (~281 AP) whose skill points were fully reset, needs
a concrete allocation to fight, PvE-focused (grinding + Land of the Morning Light).

## ⚠️ Sourcing caveats (read first)

- The only authoritative English written guide, **[BDFoundry Maegu](https://www.blackdesertfoundry.com/maegu-class-guide/)**,
  was **last updated 2023-12-11 and is Succession-only** (its author notes Awakening is absent). So
  **Succession skill names are verified; Awakening names are LOW confidence** (assembled from search
  summaries).
- The current official forum guides (NA/EU Succession `_topicNo=69349` ~2025-09-19; Asia Awakening
  `_topicNo=109263` 2025-04-20) are **JS SPAs that don't render to fetch** — existence/dates
  confirmed, bodies not extracted. Verify combos/add-ons in-browser or via the class Discord.
- **The "which rework reset the points" question is unresolved.** BDO auto-refunds SP whenever a
  class kit is reworked (or on a returning login after kit changes) — that almost certainly explains
  the zero-SP state — but **no single dated "Maegu rework" patch could be pinned**, so any claim that
  Succ-vs-Awa balance shifted on a specific date is unverified. A 2025-09 forum feedback thread
  actually complained Maegu was *behind* the rework wave, not freshly reworked.

## Recommendation: **Succession** (for this player, now)

1. He already knows it → no relearning while also re-spending points and re-gearing.
2. Best-supported + best-rated PvE spec: the only full written skill+add-on build is Succession's;
   2026 tier aggregators put Succession Maegu ~A-tier for consistent grinding. Awakening PvE guidance
   is thinner and its balance edge is unverified.
3. Cheaper/faster ramp — leans on the existing charm (main) weapon; Awakening pushes awakening-weapon
   investment he may not want mid-return.
4. Clears LotML grinding + questing comfortably at ~281 AP / Lv62.

_(Aggregator tier claims = secondary sources, not the class Discord — treat "Succession stronger for
PvE" as majority view, not a patch-sourced fact.)_

## Succession — SP priority (verified names, BDFoundry)

All skill *level* gates are met at Lv62; the only limit is total SP, and a Lv62 char has earned well
over the **~981 SP** the full build needs — so nothing must be skipped for SP. Take top-down:

1. **Spirit Step** + **Chain: Spirit Step** — core mobility.
2. **Path of Petals** — dash with an i-frame (main defensive tool; Maegu has no S-block / no Q-block).
3. **Prime: Foxspirit Tag** — primary spammable ranged damage.
4. **Prime: Bared Claws**, **Bristling Sparks** — core melee/charm damage.
5. **Absolute: Soulflame**, **Absolute: Soulsnare** — main AoE nukes.
6. **Prime: Heavenward Dance**, **Prime: Petal Play**, **Prime: Flower Shroud** — AoE + add-on carriers.
7. **Foxflare**, **Spirit Swirl** — add-on carriers / debuffs.
8. **Absolute: Charmed**, **Soul Tear** — utility / escape / extra hit.
9. **Absolute: Petal Blast**, **Prime: Spirited Away**, **Lurking Claws**, **Prime: Ghost Bomb** — fill out.
10. **Passives** (Maegu is an Evasion class — evasion passive + skill).
11. **Weight Training LAST** (carry weight only).

## Awakening — LOW confidence (needs a dedicated guide / class Discord)

Fast melee "dance" with twin Foxtail fans. Rated below Succession for PvE in the aggregator lists
(soft signal). Reported skill names (unverified): Foxflare Stroke/Fleche/Ambush/Encore, Emberclaw
Slash/Sweep/Finale/Torrent, Twirling Foxflare. Priority logic that's safe despite name uncertainty:
Emberclaw damage line + Flow follow-ups first → Foxflare fan AoE → keep pre-awakening utility (Path
of Petals i-frame, Spirit Step) → prioritize Super Armor/Frontal Guard skills for grinding → passives
→ Weight Training last. **No verified add-on table — do NOT reuse the Succession add-ons on Awakening.**

## Loading / resetting skills in-game (both specs)

- **No importable player-to-player skill code exists** in BDO. Presets are account-local: **Skill
  window (K) → Skill Preset** to save/load your own trees (+ add-ons + quickslots).
- **To reset SP:** use a **Secret Book of Old Moon** in a **safe zone (town)**, or visit a **Skill
  Instructor NPC** in a major town. ([GrumpyG](https://grumpygreen.cricket/bdo-skills/))
- Optional: mirror the build in the **Garmoth skill calculator** as a visual reference (browser
  share-link only, not an in-game import).
