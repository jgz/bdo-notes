Godr-Ayed Weapon Removal
With this update, Godr-Ayed Weapons are being removed as a gear progression option. First introduced in 2022, Godr-Ayed Weapons were released to ease the burden of enhancement by breaking down the upgrade path from TET (IV) to PEN (V) Blackstar Weapons, which were the top-tier gear at the time. However, as PEN (V) Blackstar Weapons have become more accessible, we determined that Godr-Ayed Weapons were no longer necessary.
Removed Godr-Ayed Weapons.

Node & Conquest War
We have recently received reports from Adventurers that ships were being used to destroy annex buildings too quickly in Node Wars and Conquest Wars. Upon investigation, we confirmed that multiple ships were dealing more damage than intended.

While using ships in inland PvP content such as Node Wars and Conquest Wars can be a strategic option, we want to avoid it becoming a mandatory tactic due to excessive damage. Therefore, adjustments have been made to ship damage.

UI
Production Node Status UI
We have added a Production Node Information tab to the World Map (M) to provide a clearer overview of your production activities. This new function allows you to instantly distinguish activated Nodes with and without a worker. We expect this to make node management significantly easier. We have also added a function to minimize the UI so you can toggle it as needed. We will continue to apply improvements to make node management more efficient.
Added the Production Node Information tab to the World Map.

You can now check activated and deactivated nodes within this tab.
Deactivated Nodes: Nodes that are active but have no worker assigned.
Activated Nodes: Nodes where a worker is currently assigned.
You cannot move to another node while viewing a node. You must exit viewing the current node before you can select a different one from the list.

Worker Progress UI Improvements
To make it easier for you to see your workers' progress, we have added a function that displays the destination via Work Progress Information in the World Map. This improvement provides more intuitive information, allowing you to check your workers' tasks and progress at a glance.
Improved the UI in the World Map (M) to show each working worker's destination.

Worker List Improvements
We have made a few improvements to provide a more intuitive experience while managing your workers. Firstly, clicking the name of the node your worker is at will open the map at that location, so you can more easily identify where they are. Additionally, you could not use Stamina recovery items such as Beer or Grilled Bird Meat if the Stamina would exceed the maximum. Now, you will be able to use the items to top up their Stamina even if it reaches the maximum.
Improved the UI so you can press the working worker's node name to move to it on the World Map.
Added the Fully Recover Stamina function.

You can now recover the Stamina of all workers to their maximum at once.
This function uses additional recovery items to recover a worker's Stamina up to the maximum.
The recovered Stamina will not exceed the maximum.

Example: If a worker has 33/35 Stamina, using Grilled Bird Meat (+3 Stamina) will result in 35/35, not 36/35.

Improved Recommended AP Display on World Map
A monster zone's optimal AP is more accurate when viewed based on Total Stats rather than Displayed Stats. You can now check the optimal AP of monster zones in the World Map (M) based on Total Stats.
Improved the Monster Zone Info UI so that selecting "View Total Stats" will now display the optimal AP on the World Map (M) using your Total Stats AP.

Tag Character UI Improvements
We have improved functions related to the Tag Character UI, as it was difficult to check the list and identify the character you are currently logged in with. Firstly, we have reorganized the character list to fit more on a single screen so that multiple characters can be checked simultaneously. Additionally, your current character will always appear at the top of the list, with a border around it to make it easier to identify.
Improved the UI to show more characters on a single screen instead of one line at a time.
Improved the list so the currently online character appears first.
Applied a border effect around the portrait of the currently online character for easier identification.

Revamped the Guild Boss Subjugation List UI.

All 5 types of Guild Bosses can now be viewed on one screen.
The Find Location button has been changed to an icon and moved next to each Guild Boss name.
