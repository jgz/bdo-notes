## Decision: run **Succession**

You already play Succession, and it's the right call right now: it's the **better-supported and
higher-rated PvE spec** (the only class with a full written skill + add-on build, ~A-tier for
grinding), it **leans on your existing charm weapon** so the ramp is cheap, and it clears Land of the
Morning Light comfortably at your ~281 AP. Awakening is worth *trying* later, but for "spend points
and go," Succession wins. _(Awakening guidance is thinner and its balance edge is unverified — see
research.)_

## First: reset is already done, now allocate

You have **more than enough SP** at Lv62 for the entire build (~981 needed, you've earned far more),
so you won't skip anything for lack of points. If you ever need to re-reset: **Secret Book of Old
Moon** in town, or a **Skill Instructor NPC**. Save it in **Skill window (K) → Skill Preset** once
built. (BDO has no shareable skill code — you input it manually; the order below is that input list.)

## Succession — input in this order

Take top-down; the first few make you combat-functional immediately, the rest complete the kit.

1. **Spirit Step** + **Chain: Spirit Step** — mobility.
2. **Path of Petals** — your i-frame dash (**main defense** — Maegu has no S-block or Q-block, so this matters).
3. **Prime: Foxspirit Tag** — primary spammable ranged damage.
4. **Prime: Bared Claws** + **Bristling Sparks** — core melee/charm damage.
5. **Absolute: Soulflame** + **Absolute: Soulsnare** — main AoE nukes.
6. **Prime: Heavenward Dance**, **Prime: Petal Play**, **Prime: Flower Shroud** — AoE + they carry add-ons.
7. **Foxflare** + **Spirit Swirl** — add-on carriers / debuffs.
8. **Absolute: Charmed** + **Soul Tear** — utility / escape / extra hit.
9. **Absolute: Petal Blast**, **Prime: Spirited Away**, **Lurking Claws**, **Prime: Ghost Bomb** — fill out.
10. **Passives** (Maegu is an Evasion class — take the evasion passive + skill).
11. **Weight Training LAST** — carry weight only.

> Just need to fight *right now*? Steps **1–5** give you mobility, a defensive i-frame, and your main
> ranged + AoE damage. That's a functional grinding kit; add the rest as points allow (you have them).
