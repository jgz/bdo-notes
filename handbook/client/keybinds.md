# Keybindings — Jon's custom layout

> Captured **2026-08-21** from in-game Settings → Hotkey & Input
> ([screenshots](../../research/account/keybinds/)). Movement is **ESDF** with everything rebound
> around it. **BDO stores keybinds server-side, not on disk** — so this hand-transcribed table (and
> the [visual keymap](keymap.html)) is the record; re-capture by screenshotting the Key Settings
> tabs if Jon rebinds anything. Quick Slot (1–0) and Misc/camera hotkeys are **stock defaults** and
> not reproduced here.

## The ESDF core

| Key | Function |
|---|---|
| **E** | Move Forward |
| **S** | Move Left |
| **D** | Move Backward |
| **F** | Move Right |

Evasion is the usual **double-tap movement** (the "(With Hotkey) Evasion" binds are left empty).
