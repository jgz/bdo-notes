## The honest framing

- **Barter is genuinely good now** — Apr 2026 added **cross-continent Level 6/7 routes** worth **50M/100M
  per good**, doubled special-barter Crow Coins, and standardized/lowered Parley cost.
- **But it's ACTIVE gameplay**, not passive: you pilot the ship the whole run, **barter goods can no
  longer be Transported**, and **L6/L7 are destroyed if your ship sinks**. This is Jon's "engaged sea
  night" money activity — separate from the passive node/cooking layer.
- **Realistic income:** a few hundred M/hr for a well-geared player; **~1.5B per refresh** in one player
  report. The "**9B/day**" figure is the optimized ceiling (endgame Carrack + weight gear + all refreshes
  + nonstop play), not typical. _(No authoritative post-buff M/hr published — player estimates.)_

## The ship ladder — build the BARTER (cargo) branch

Two branches converge at the Carrack. Barter = the **cargo/weight** branch (Sailboat→Caravel), **not**
the combat branch (Frigate→Galleass).

| Tier | Ship | For barter? | Key stats |
|---|---|---|---|
| T1 | Bartali Sailboat | learn only | tiny weight — storage-limited every run |
| T2 | **Epheria Sailboat** (→ Improved) | ✅ first real barter ship | 5,000 LT |
| T2 | Epheria Frigate | ❌ combat | more cannons, less cargo |
| T3 | **Epheria Caravel** (from Sailboat) | ✅ **the barter workhorse — target** | **10,000 LT, 30 slots**, 2 cannons/side |
| T3 | Epheria Galleass (from Frigate) | ❌ combat / sea-monster | 8 cannons, less cargo |
| T4 | **Carrack: Advance** (from Caravel) | ✅ **endgame barter** | **16,500 LT, 40 slots**, 110% speed |
| T4 | Carrack: Balance / Volante / Valor | Balance = meh; Volante/Valor = combat | — |

**Path: Bartali → Epheria Sailboat → Epheria Caravel → Carrack: Advance.** The Caravel is *the* barter
ship (doubled weight vs Sailboat); Carrack Advance is the long-term chase.

## Building it (the grind)

- **4 ship parts** per ship (figurehead / plating / cannon / sail): craft green grade → enhance to **+10**
  → craft blue grade → +10. Enhanced with **Tidal Black Stone** (id **756001**; from barter vouchers via
  Ravinia). _(Epheria **Sailboat/Frigate** gear instead uses **Verdant Black Stone**, id **45506**.)_
  Ship-part items are per-ship sets (e.g. Caravel: Brass Figurehead 49653, Enhanced Plating 49654, Mayna
  Cannon 49657, White Wind Sail…). ⚠️ exact stone counts disputed across sources — verify in-game.
- **Ravinia's 7-day Ship Upgrade Log** (NPC Ravinia, **Crow's Nest** island): one quest/day, gives
  ~**1,000 Crow Coins + 10 Tidal Black Stones + ~half the crafted upgrade components** → roughly **halves
  the grind**. Do it the day you're eligible.
- **Hull permit** (Caravel): ~**400M silver** from Philaberto Falasi, Port Epheria. (Carrack permits:
  Advance 59316 / Balance 59317 / Volante 59318 / Valor 59319.)
- **Rough Caravel mat pile:** Graphite / Timber / Adhesive "for Upgrade" **×100 each** (from Zinc Ingots,
  Old Tree Bark, Red Tree Lump, Tree Saps + **Sea Monster's Ooze**, id **45507**), plus Island Tree Coated
  Plywood ×100, Rock Salt Ingot ×100, Glue/Seaweed ×4, **Sea Monster's Ooze ×300, Tidal Black Stones ×40**.

**What Jon's empire covers vs what he earns at sea:**
- ✅ **Workers + processing** = the land bulk (Graphite / Timber / Adhesive and their ore/wood/sap inputs).
- ⚓ **Must earn actively at sea** = Sea Monster's Ooze, Rock Salt, monster drops, barter vouchers /
  Crow Coins, and the silver permits. Workers can't shortcut these.

## The barter money loop

Load **land goods** (vinegar/beer/fleece…) at a Wharf Manager → sail to a **Barter NPC** → exchange up
the chain **Land → L1 → … → L7** (or divert **L4 → Crow Coins**). Sell high tiers to a Wharf Manager.

| Tier | NPC value | note |
|---|--:|---|
| L3 | 1M | |
| L4 | 2M | the Crow Coin exchange tier |
| L5 | 7.5–15M | |
| **L6** (new) | **50M** | cross-continent, 2,000 LT |
| **L7** (new) | **100M** | cross-continent, at-risk |

- **Parley:** family pool starts 1,000,000; ~**21,650 per exchange** post-buff (Value Pack −10%); refills.
- **Weight is the gate** (can't barter overweight) → **Trader's Clothes + Seafood Cron + weight crystals**
  (~+1,090 LT builds). Bigger ship = fewer deposit trips = more silver/run.
- **Refresh:** routes refresh on a 2h cooldown; ~2 manual refreshes/day (3 w/ Value Pack).

## Crow Coins / Sea Coins

- **Earn:** sea-monster hunting (best ~**1,000/hr** Lekrashan), special barters (doubled to ~4–5k),
  Ravinia 7-day (1,000), daily sailing quests (~480/day), Suspicious Cargo Ships.
- **Best exchange:** trade coins for **Caphras Stone bundles** and resell — *not* most shop items (only buy
  ship-upgrade parts if actually building that ship). Bulk exchange moved to **Crow's Nest** (Apr 2026).

## Sailors

- **Recruit:** do the **Oquilla's Eye / [The Great Expedition]** questline (Lv 50+) → free sailor + slots;
  buy **Sailor Contract Certificate** (3M) → hire from spawns at Velia / Port Epheria / Iliya (~30–60 min).
  More slots via **Captain's Medallion** (Pearl, max 14). **Otters** via Crio (2,000 Crow Coins).
- **Stats → buffs:** Endurance=Speed, Wits=Accel, Awareness=Turn, Strength=Brake. **Goblin sailors** =
  best weight/speed. Typical trade crew: **3 Powerful + 1 Smart**. Level to 10 (mostly sea-monster kills).
- **Upkeep:** feed **Raisin Bread** (Condition), ship **rations** (Wharf "Buy Supplies"), **repair kits**.

## Leveling Sailing + Barter (Jon is Beginner in both)

- **Sailing:** daily sailing quests + sea-monster hunting. **Milestone: Skilled 1 → BreezySail** (the big
  travel-speed skill). Sailing Mastery scales ship stats (~1,500 ≈ +15%). Boost: **Celerity Draught +20%**.
- **Barter:** count-based — ~**70 barters → L4 routes**, ~140 → special barters, ~1,000+ → "brilliant"
  mats. L6/L7 barters give more Barter EXP.
