# Black Desert Online — Jon's playbook

Notes, mechanics, and planning for **Black Desert Online**, built for Jon as he **picks the game
back up after ~2 years away**. The account is already well-developed — many high-level characters
and strong **life skills** (guru cooking, high-tier processing, accumulated CP/workers/nodes) — but
**light on combat gear**. This repo exists to get organized: capture where the account actually is,
figure out what changed while Jon was gone, and turn that into a plan he can run without re-guessing
every time.

## Layout

- **`handbook/`** — the **reader layer**, plain language, written to be skimmed. `status.md` is the
  living snapshot; `systems-overview.md` is the master map; `account/` holds Jon's characters, gear,
  and empire; `lifeskills/` covers the life-skill economy. New domain folders appear as we deep-dive.
- **`research/`** — the **evidence layer**. Dense, sourced, dated. Every load-bearing claim traces to
  a primary source (patch notes, current database/wiki, reputable creator, or an in-game screenshot
  Jon provides). The handbook cites this; it is not the reading layer. See
  [`research/README.md`](research/README.md).
- **`tools/`** — scripts for fetching/refreshing research and running the numbers, as we build them.
- **`AGENTS.md`** — instructions for AI assistants. Short version: **never guess, source everything,
  date everything** — the game changes constantly and Jon's been away 2 years.

## House rules

- Durable facts land in the **handbook first, in plain language**; `research/` holds the receipts.
- Every claim carries a **source and a date** — see `AGENTS.md`. BDO rebalances patch to patch; a
  number without a date is already suspect, and 2-year-old memory is not a source.
- **Reason from the account.** Advice is only as good as the picture of Jon's actual gear, life
  skills, and empire — keep the account pages current and start there.
- **Play to strengths.** Jon is life-skill-rich and gear-poor; plans should exploit the cooking /
  processing / empire advantages he already has, not start from scratch.
